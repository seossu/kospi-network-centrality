네트워크 기반 퀀트 전략

Z-Score Composite + 월간 리밸런싱 대시보드

전략 개요

1

상관행렬 구축

60일 일별 수익률로 종목 간 상관행렬을 계산하고, Marchenko-Pastur 분포로 노이즈를 제거합니다.

2

네트워크 중심성 계산

정제된 상관행렬을 인접행렬로 변환하고, 시가총액으로 보정된 Cap-Scaled Eigenvector Centrality를 산출합니다.

3

Z-Score 복합점수

중심성 Z-Score에서 시장 모드 노출(λ₁ loading)을 차감하여 복합점수를 구성합니다.

4

5분위 포트폴리오

복합점수 상위 20%(Q5)를 등가중으로 편입하고, 월 1회 리밸런싱합니다.
