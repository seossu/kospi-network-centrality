# 데이터

원본 데이터는 용량(파일당 최대 약 290MB)과 데이터 제공처 라이선스 때문에 저장소에 포함하지 않았습니다.
아래 파일을 이 폴더(`data/`)에 넣으면 `src/` 스크립트가 그대로 실행됩니다.

| 파일 | 행(index) | 열 | 내용 |
|---|---|---|---|
| `수정주가_거래대금필터_code.csv` | `Date` (일별) | 종목코드 (`A005930` …) | 수정주가. 상관 네트워크 계산에 사용 |
| `현금배당포함.csv` | `코드명` (일별 날짜) | 종목명 (`삼성전자` …) | 배당 포함 수정주가. 수익률 계산에 사용 |
| `시가총액.csv` | `코드명` (일별 날짜) | 종목명 | 시가총액 (쉼표 포함 숫자) |
| `거래대금.csv` | `Date` | 종목코드 | 일별 거래대금. Amihud 비유동성 계산에 사용 |
| `60_거래대금.csv` | `Date` | 종목코드 | 60일 평균 거래대금. 유동성 필터에 사용 |
| `4팩터.csv` | `Date` | `KOSPI, HML, SMB, MOM, CD91` | 팩터 지수 수준값과 CD91 금리(%). 알파 회귀에 사용 |

- 종목코드 기준 파일과 종목명 기준 파일은 **열 순서가 같아야** 합니다. 코드↔종목명을 열 순서로 매칭합니다.
- 기간은 2000-01 ~ 2025-12 (3,751종목)입니다.
- `experiments/v1_leadlag_monthly.py`는 별도로 사전 계산된 파일(`daily_scores.csv`, `lead_lag_pairs.csv` 등)을 사용하며, 이 파일들은 보관되어 있지 않습니다.
